# Akela

Akela is an open-source ERP for any kind of business, built around Locations that keep working when the internet is down.

## Where development happens

The primary repository is on OneDev: https://onedev.eusou.dev.br/akela

The GitHub repository is a read-only mirror, updated automatically from OneDev. Do not open pull requests or issues on GitHub; open them on OneDev.
